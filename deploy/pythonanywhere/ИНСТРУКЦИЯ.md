# Инструкция: публикация сайта на PythonAnywhere (бесплатно)

PythonAnywhere запускает сайты на Python бесплатно. Нужно зарегистрироваться,
загрузить код, вставить готовый файл настроек — и сайт получает постоянный
адрес вида `https://ВАШ_ЛОГИН.pythonanywhere.com`.

## Шаг 1. Регистрация

1. Откройте https://www.pythonanywhere.com/account/register/
   (кнопка "Register" вверху справа на https://www.pythonanywhere.com)
2. Придумайте **Username** — это будет адрес сайта:
   `https://username.pythonanywhere.com`
3. E-mail, пароль → "Create your account".
4. Подтвердите письмо с почты (зайдите по ссылке из письма).

## Шаг 2. Загрузка кода

1. В панели сверху выберите вкладку **Files**.
2. Нажмите **Upload file**, выберите архив
   `school-portal-pythonanywhere.zip` (он у вас в папке «Документы»).
3. Перейдите в консоль: вкладка **Consoles** → **Bash**.
4. Вставьте по одной команде и жмите Enter:

```bash
cd ~
unzip -o school-portal-pythonanywhere.zip -d school-portal
cd school-portal
pip install --user -r requirements.txt
```

## Шаг 3. Настройка сайта

1. Откройте вкладку **Web** (вверху).
2. Нажмите **Next** по подсказкам (тип — Manual configuration,
   интерпретатор — последний Python 3.x, который предложат).
3. Внизу будет ссылка **"your WSGI configuration file"** — нажмите на неё,
   откроется файл. **Выделите всё** (Ctrl+A) и **удалите**.
4. Скопируйте туда целиком содержимое файла
   `deploy/pythonanywhere/wsgi-TEMPLATE.py` из этого архива
   (там уже прописано, откуда брать сайт).
5. Сохраните (Ctrl+S / кнопка "Save").

**Важно:** в первых двух строках пути `/home/USERNAME/...` замените USERNAME
на свой логин PythonAnywhere, если он отличается от `annasochin`.

## Шаг 4. Запуск

1. Во вкладке **Web** нажмите оранжевую кнопку **Reload**.
2. Откройте адрес `https://ВАШ_ЛОГИН.pythonanywhere.com` — сайт работает!

## Шаг 5. Первые настройки

- Войдите на сайте как администратор: логин `admin`, пароль `admin123`
  и **сразу смените пароль** (создайте свой аккаунт администратора в
  «Пользователи», старый отключите).
- Загруженные учителями файлы и база хранятся в папке
  `/home/USERNAME/school-portal/` — база `school.db`, файлы в `uploads/`.

## Письма подписчикам (необязательно)

Во вкладке **Web** → внизу **Environment variables** (или в консоли):
задайте SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD, SMTP_FROM.
Без них сайт работает, но письма не отправляются.

## Обновление сайта после изменений

1. Во вкладке **Files** удалите старые файлы или через консоль:
```bash
cd ~
rm -rf school-portal
unzip -o school-portal-pythonanywhere.zip -d school-portal
cd school-portal && pip install --user -r requirements.txt
```
2. Нажмите **Reload** во вкладке Web.

## Ограничения бесплатного тарифа

- Сайт засыпает после 3 минут простоя — при визите просыпается сам
  (первый переход может занять 5–15 секунд).
- Диск 512 МБ, одна веб-страница — школьному порталу достаточно.
- Сайт работает на поддомене `username.pythonanywhere.com`
  (свой домен — только на платных тарифах).
