# Школьный портал олимпиад и конкурсов

Сайт **МБОУ СОШ № 61 им. П. Е. Ладана**, где учителя размещают анонсы олимпиад,
конкурсов и своих творческих разработок (с файлами и ссылками), а ученики
находят информацию по предметам.

## Возможности

- Главная страница с поиском, фильтрами по предмету и типу, отметкой «только действующие»
- **Календарь** олимпиад и конкурсов: месяц с цветными метками (дата мероприятия,
  последний день подачи заявок) и список ближайших событий
- Карточка объявления: описание, дата мероприятия, срок подачи заявок, ссылка, вложения
- **Подписка учеников по e-mail** на анонсы по предмету (или на все) — письма
  уходят автоматически при публикации нового объявления, отписка в один клик
- Регистрация учителей (ФИО, предмет, логин, пароль)
- Личный кабинет: свои анонсы, статус, редактирование, удаление
- Загрузка файлов (положения, методички, программ) — до 15 МБ на файл
- Модерация: объявления публикует администратор
- Управление пользователями и подписчиками

## Запуск на компьютере (Windows)

1. Установите Python 3.10+ с сайта python.org (галочка «Add to PATH»).
2. Дважды кликните `run.bat` — он сам создаст окружение и установит всё нужное.
3. Откройте в браузере: http://127.0.0.1:8000

Первый вход:
- **Администратор**: логин `admin`, пароль по умолчанию `admin123` —
  на новом разворачивании смените его сразу после первого входа
  («Мой кабинет» → «Сменить пароль»); на действующем сайте этот пароль
  уже сменён и упомянут здесь лишь как исходный.
- **Учитель**: кнопка «Регистрация учителя» на сайте.

## Как это работает

- База данных — файл `school.db` (SQLite), создаётся автоматически.
- Загруженные файлы складываются в папку `uploads/`.
- Путь для данных задаётся переменной окружения `DATA_DIR`
  (по умолчанию — папка проекта).
- Новые и отредактированные объявления уходят на проверку, после одобрения
  появляются на главной, в календаре и уходят подписчикам письмами.

## Публикация на сервере школы

Есть три простых варианта — выберите тот, что доступен вашему школьному
администратору или хостингу.

### Вариант 1. VPS (Timeweb, Selectel, любой Linux) — рекомендуется

```bash
# на сервере (Ubuntu/Debian)
sudo apt update && sudo apt install -y python3-pip nginx git
sudo mkdir -p /srv/school-portal && sudo chown $USER /srv/school-portal

# загрузите проект (например, архивом) в /srv/school-portal
cd /srv/school-portal
pip3 install -r requirements.txt

# сервис, который запускает сайт
sudo cp deploy/school-portal.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now school-portal

# сайт через Nginx (домен школы)
sudo cp deploy/nginx.conf /etc/nginx/sites-available/school-portal
# отредактируйте server_name — укажите домен
sudo ln -s /etc/nginx/sites-available/school-portal /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

Не забудьте: замените `SECRET_KEY` в `/etc/systemd/system/school-portal.service`
на длинную случайную строку (`python3 -c "import secrets; print(secrets.token_hex(32))"`),
а пароль администратора по умолчанию `admin123` смените сразу после первого
входа («Мой кабинет» → «Сменить пароль»).

### Вариант 2. Docker

```bash
cd school-portal/deploy
docker compose up -d --build
```

Сайт поднимется на порту 8000, данные сохранятся в томе `portal-data`
(переживут обновление образа). Настройки рассылки — в `docker-compose.yml`.

### Вариант 3. Хостинг с Python (PythonAnywhere)

1. Загрузите папку проекта на хостинг.
2. В настройках веб-приложения укажите WSGI-файл `deploy/wsgi.py`
   (внутри он импортирует `app.main:app`).
3. В консоли хостинга выполните `pip install -r requirements.txt`.
4. Добавьте папку `app/static` как статическую.

### Настройка рассылки писем (необязательно)

Задайте переменные окружения на сервере:

| Переменная | Пример |
|---|---|
| `SMTP_HOST` | `smtp.yandex.ru` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `portal@school61.ru` |
| `SMTP_PASSWORD` | пароль приложения |
| `SMTP_FROM` | `portal@school61.ru` |

Если SMTP не задан, подписки собираются, но письма не отправляются —
администратор видит об этом предупреждение в разделе «Подписчики».
Проверить почту можно кнопкой «Отправить тест».

## Структура проекта

```
school-portal/
├── app/
│   ├── main.py          # все страницы и логика
│   ├── db.py            # база данных SQLite
│   ├── mailer.py        # отправка писем по SMTP
│   ├── security.py      # хеши паролей
│   ├── static/style.css # стили
│   └── templates/       # HTML-шаблоны
├── deploy/              # файлы для публикации на сервере
│   ├── Dockerfile
│   ├── docker-compose.yml
│   ├── school-portal.service   # systemd (VPS)
│   ├── nginx.conf              # прокси-сервер
│   └── wsgi.py                 # для хостингов с WSGI
├── uploads/             # загруженные файлы (создаётся сама)
├── test_smoke.py        # автотесты основных сценариев
├── requirements.txt
└── run.bat              # запуск одной кнопкой
```
